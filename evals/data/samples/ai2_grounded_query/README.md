# AI2 grounded-query samples

These JSON inputs are human-authored probes for the AI2 question-answering
contract. They cover grounded lookup, clause/annex relations, comparison,
uncertainty, scope, policy blocking, bounded answers and Vietnamese Unicode.

The expected values are maintained separately in the domain ground truth file.
They encode safety and evidence invariants, not outputs copied from the mirror.
The fixture names select representative AI1 handoff conditions; they are not
treated as business ground truth.
