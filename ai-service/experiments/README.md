# Experiment definitions

`definitions.yaml` lists E0–E6. The runner reads `experiments` from the selected complete config (`configs/default.yaml` by default). Edit that config to add a variant, or select IDs with `--experiments E0,E1`. `configs/experiments.yaml` is a reference fragment, not a merged override file.

See [experiment methodology](../docs/EXPERIMENTS.md). No measured accuracy results are included here.
