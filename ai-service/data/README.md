# Local dataset

Use `manifest.example.csv` as a template for `manifest.csv`. Example documents are not supplied. Store authorized source PDFs in `raw/`, generated variants in `generated/`, and annotations in `ground_truth/`.

See [dataset instructions](../docs/DATASET.md) and [baseline commands](../README.md). Real data and annotations are ignored by Git. Keep `.gitkeep` placeholders only; never force-add private documents.
